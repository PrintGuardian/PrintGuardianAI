# PrintGuardianAI dashboard

A React dashboard for the PrintGuardianAI backend.

## Run locally

1. Start the API on port 8000.
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open the address shown by Vite.

Vite proxies `/api` to the local FastAPI server. For a separately hosted API, set `VITE_API_BASE_URL` when building the dashboard.
